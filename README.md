# Used Car Price Prediction

A beginner-friendly Python machine learning project that estimates a used car's sale price from its details.

## Inputs

The model uses the car's brand, model, year, mileage, fuel type, transmission, number of previous owners, condition, city, and engine size.

The model predicts `sale_price`, measured in Indian rupees (INR).
